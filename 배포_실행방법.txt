========================================
배포 실행 방법 (명령 프롬프트)
========================================

⚠️ 주의: 명령어를 한 줄씩 실행할 때는 디렉토리 변경이 제대로 되었는지 확인하세요!


방법 1: 한 줄씩 실행 (디렉토리 확인 필수)
----------------------------------------
1. 명령 프롬프트(cmd) 열기

2. 다음 명령어 실행:
   cd /d "D:\1-2. CURSOR_지도기반사이트만들기"

3. 현재 디렉토리 확인:
   cd
   (출력이 "D:\1-2. CURSOR_지도기반사이트만들기"인지 확인)

4. 빌드 실행:
   npm run build


방법 2: 한 번에 실행 (권장)
----------------------------------------
명령 프롬프트에서:

cd /d "D:\1-2. CURSOR_지도기반사이트만들기" && npm run build


방법 3: 배치 파일 사용 (가장 간단)
----------------------------------------
1. 파일 탐색기에서 프로젝트 폴더 열기
2. deploy-all.bat 파일 더블클릭


방법 4: 배치 파일을 명령 프롬프트에서 실행
----------------------------------------
명령 프롬프트에서:

cd /d "D:\1-2. CURSOR_지도기반사이트만들기"
deploy-all.bat


========================================
문제 해결
========================================

Q: "Could not read package.json" 오류가 발생합니다.
A: 디렉토리가 제대로 변경되지 않았습니다.
   다음 명령어로 확인하세요:
   
   cd /d "D:\1-2. CURSOR_지도기반사이트만들기"
   cd
   dir package.json
   
   package.json 파일이 보이면 정상입니다.


Q: 한글 경로 때문에 오류가 발생합니다.
A: 배치 파일을 사용하거나, 다음 명령어를 사용하세요:
   
   chcp 65001
   cd /d "D:\1-2. CURSOR_지도기반사이트만들기"
